# Module 01 Assessments 教师答案

> **仅供教师使用：**当前 GitHub 教师仓库包含本答案；发布学员资料时不要复制本文件。“教学诊断”用于决定要回收的误解，不用于给起点不同的学员扣分。

## Entry Quiz 答案（8 题）

| 题号 | 答案 | 教学诊断（一句） |
|---:|---|---|
| 1 | **B**：可执行命令使用 `package main` 中的 `func main()` 作为入口。 | 选其他项说明学员仍在寻找 Java Class、注解或实例方法式入口。 |
| 2 | **B**：`:=` 可在函数体内声明局部变量并推断类型。 | 选其他项说明需要回收 Go 的名称/类型顺序、短声明作用域或未使用变量编译规则。 |
| 3 | **B**：Go 用 `for ready { ... }` 表达 while 式循环。 | 选其他项说明学员假设 Go 保留了 Java 的多种循环关键字。 |
| 4 | **B**：Go `switch` 默认在命中 case 结束后离开，只有显式 `fallthrough` 才贯穿。 | 选 A 或 C 说明 Java `switch` 的贯穿与 `break` 习惯仍在影响行为预测。 |
| 5 | **C**：`func Grade(score int) (string, error)` 把正常结果和可预期失败都写入契约。 | 选 A、B 或 D 说明需要对比空值哨兵、panic、Java 异常与 Go 显式 `error`。 |
| 6 | **B**：Array 赋值复制全部元素，修改 `b` 不改变 `a`。 | 选 A 说明学员把 Java 数组引用语义直接套用到了 Go Array。 |
| 7 | **C**：comma-ok 同时返回值和 key 是否存在。 | 选 A 说明学员还不理解 Map 缺失 key 会返回值类型零值。 |
| 8 | **B**：`len("Go你好")` 为 8 bytes，而这个字符串有 4 runes。 | 选 A 或 C 说明学员仍把字符数、UTF-16 code unit 或固定宽度编码当成 Go String 的长度。 |

## Exit Quiz 答案（核心 14 题 + 选做 3 题）

| 题号 | 答案 | 教学诊断（一句） |
|---:|---|---|
| 1 | **B**：Array 作为参数时按值复制，`change` 只修改形参副本。 | 选 A 说明学员还没有把“Go 只有值传递”应用到 Array 参数。 |
| 2 | **B**：`middle` 与 `scores` 共享底层数组的对应区域，因此修改反映为 `[60 100 90]`。 | 选 A 说明学员把 Slice 语义错当成了 Array 的深副本。 |
| 3 | **B**：`base` 容量已满，`append` 为 `grown` 分配新底层数组，所以后续修改不影响 `base`。 | 选 A 说明学员认为 Slice 之间的共享关系在 `append` 后必然永久保留。 |
| 4 | **A**：两次读取的值都是 0，但 comma-ok 用 `true` 和 `false` 区分存在性。 | 选 B、C 或 D 说明学员仍用 nil、异常或单一零值理解 Map 缺失 key。 |
| 5 | **B**：`"A你"` 占 4 个 UTF-8 bytes，`range` 却以 2 个 rune 迭代。 | 选 A 或 C 说明学员仍把 byte 索引与 Unicode code point 迭代混为同一种长度。 |
| 6 | **B**：修改同一对象的 `UpdateScore` 用指针接收者，只读且返回副本的 `Snapshot` 可用值接收者。 | 选 A、C 或 D 说明学员还不能从“是否修改调用者的值”推导接收者。 |
| 7 | **A**：`pass(60)` 为 true、`pass(59)` 为 false，因为闭包保留了对 `min` 的访问。 | 选其他项说明学员把外层函数返回误解为所有局部状态都立即不可访问。 |
| 8 | **C**：`defer` 注册的 `end` 在当前函数返回前执行，顺序为 start、operation、end。 | 选 A 说明学员把 `defer` 误解为声明处立即调用。 |
| 9 | **B**：失败明确显示 actual 80 和 want 80.5，应先检查整数除法发生在类型转换之前的最小假设。 | 选 A、C 或 D 说明学员尚不能把测试名和 actual/want 转成可验证的下一步。 |
| 10 | **B**：修改 `Find` 返回的值副本不能改变书内记录，再次查询仍为 90。 | 选 A 说明学员未能用可观察的二次查询验证返回副本的隔离性。 |
| 11 | **B**：基本类型变量声明后分别使用整数、布尔和字符串零值。 | 选 A、C 或 D 说明学员还没有建立 Go 的零值模型。 |
| 12 | **A**：多值 `case` 表示 OR；没有 `fallthrough` 时只执行当前分支，加上后才无条件进入下一个分支。 | 选 B、C 或 D 说明学员仍把 Go `switch` 当成 Java 的自动贯穿模型。 |
| 13 | **B**：`strings.Fields` 按连续空白分词，不产生空单词。 | 选 A、C 或 D 说明学员需要回收 String 和 `strings` 包的基础操作。 |
| 14 | **C**：行为测试应同时确认筛选内容和顺序，不能用改期望或弱断言绕过失败。 | 选 A、B 或 D 说明学员还没有把测试当成行为契约。 |
| 15（选做） | **A**：省略的 ConstSpec 复用上一行完整表达式，所以 `d` 仍为 100；`e = iota` 使用当前声明行号 4。 | 选 B 表示没有理解省略声明复用完整表达式；选 C 表示误以为同一 const 块内 iota 被重置。 |
| 16（选做） | **B**：`copy(dst, src)` 向目标 Slice 复制 `min(len(dst), len(src))` 个元素，返回 3，未覆盖位置保持零值。 | 错误选择说明学员未掌握 `copy(dst, src)` 的方向或 `min(len(dst), len(src))`。 |
| 17（选做） | **C**：Map index 得到的 Struct value 不可寻址，不能直接给其字段赋值。 | 选 A 表示把 Map value 当成可寻址对象；选 B 表示不能区分编译错误与运行时 panic。 |

## 讲师使用方式

- Entry 某题错误超过班级一半时，在对应 Demo 中增加一次“先预测，后运行”，不延长讲授。
- Exit 的错题作为下周 Code Review 开场题；优先回收最高频的两个行为误判。
- 如学员答对但无法解释可观察结果，在课堂 [Rubric](../instructor/RUBRIC.md) 的“解释与迁移”维度记录，不改 Quiz 答案。
