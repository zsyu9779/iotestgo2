# Module 01 课堂 Lab 通用评分语言

本评分表用于四个 Block Lab 和 Scorebook 综合 Lab 的形成性反馈，不是 Task Manager 课后作业分数。Task Manager 使用独立的 [100 分评分表](../homework/task_manager/teacher/RUBRIC.md)。Entry Quiz 和 Exit Quiz 用于诊断教学，不因起点差异扣分。

## 每个 Lab 的 10 分量表

| 维度 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| 契约行为 | 所有规定正常路径符合测试 | 主路径可用，仍有一个明确失败 | 主路径不可用或改了公开接口 |
| 边界与错误 | 边界、零值和约定错误全部正确 | 能解释边界，但有一处实现不符 | 忽略边界或用不相干方式规避错误 |
| 状态与副本隔离 | 失败不污染状态，返回值不泄漏内部可变状态 | 正常修改正确，但有一个隔离性问题 | 经常丢失修改或暴露内部状态 |
| 测试反馈循环 | 能展示 RED、读出 actual/want、用最小修改变 GREEN 并运行全包回归 | 最终会运行测试，但无法说明当前失败 | 不运行指定测试，或删除/弱化测试规避失败 |
| 解释与迁移 | 能用可观察行为解释选择，并给出一个新场景 | 能说出规则，但无法连到当前代码 | 只复述语法或复制答案，无法预测行为 |

## 各 Lab 的必看证据

| Lab | 契约与边界证据 | 解释证据 |
|---|---|---|
| Block 1 Grade | 0、60、90、100 分类正确，-1/101 返回 `ErrScoreOutOfRange` | 能说明为何从高边界向低边界判断 |
| Block 2 Textstats | 中英文 bytes/runes/words 和小写词频正确，空文本返回空 Map | 能区分 Slice 共享与 Array 副本，并解释 comma-ok |
| Block 3 Student | 姓名清理、0/100 边界、失败无修改和 Snapshot 隔离全部可观察 | 能根据“是否修改同一对象”选择接收者 |
| Block 4 Scores | `Filter` 顺序不变，`AtLeast(60)` 包含 60，audit 顺序为 start/operation/end | 能说明闭包捕获了什么，以及 `defer` 何时执行 |
| Scorebook | 连续 ID、返回副本、未知 ID、空平均值、小数平均值和等级边界全部通过 | 能把第一个失败断言连回某个不变量 |

新增内容的观察证据：

- 能预测基本变量和 Struct 的零值，并区分 nil Slice 与 nil Map 的可写行为。
- 能解释 String 的 byte/rune、`range string` 的 byte offset、Slice 的底层数组共享和 Map 的无序迭代。
- 能区分多值 `case`、默认不贯穿的 `switch` 与显式 `fallthrough`。
- 能读懂并补充一个具名测试，断言结果内容、边界和顺序，而不是修改期望值绕过失败。

## 形成性等级

- **9–10：可独立迁移。**行为通过，能用测试证据解释取舍。
- **7–8：达到当日目标。**核心行为通过，少数边界或解释需复习。
- **4–6：需要定向练习。**已有部分绿色行为，但不变量或反馈循环仍不稳定。
- **0–3：需要教师结对支持。**先修复环境与第一个失败行为，不追加 Bonus。

记录分数时同时写一句可复现证据，例如“`TestAnalyze` 通过，但仍把 Slice 说成 Array 引用”，不使用“理解不够”这类无法追踪的评语。
