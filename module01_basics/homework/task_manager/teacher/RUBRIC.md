# Task Manager 作业评分表（100 分）

评分以学生所提交开发分支中的代码为准。教师先选择正确分支，再手动运行 Gitee 流水线，并结合 CLI 人工检查评分。

## 一、核心业务行为（60 分）

- **Add：18 分**
  - 标题使用 `strings.TrimSpace` 清理：5 分。
  - 空标题返回 `ErrEmptyTitle` 且不改变状态：5 分。
  - ID 从 1 开始、严格递增且删除后不复用：5 分。
  - 新任务默认未完成并返回正确副本：3 分。
- **List：12 分**
  - 按添加顺序返回完整任务列表：5 分。
  - 空列表为非 nil：2 分。
  - 返回副本，外部修改不能污染内部状态：5 分。
- **Complete：12 分**
  - 正确更新指定任务并返回更新后的副本：8 分。
  - 未知 ID 返回 `ErrTaskNotFound`：4 分。
- **Delete：10 分**
  - 正确删除指定任务且保留其余任务顺序：6 分。
  - 未知 ID 返回 `ErrTaskNotFound`：4 分。
- **接口和状态保护：8 分**
  - 保留规定的公开类型、错误变量和方法签名：4 分。
  - 所有公开返回值均不暴露内部 `*Task`：4 分。

## 二、测试与统一验收（15 分）

- 仓库内公开测试全部通过：8 分。
- 按 README 的 CLI 示例复现正常流程和错误输入，并记录结果：2 分。
- `scripts/grade.sh` 的 gofmt、Vet、测试、构建四步全部通过：5 分。

不得通过删除测试、弱化断言或修改验收脚本获得分数；发生此类情况时，本项为 0 分，并按原始验收标准重新评分业务行为。

## 三、CLI 完整性（10 分）

- `add`、`list`、`complete`、`delete`、`exit` 五个命令均可用：5 分。
- 标题和整数 ID 解析正确，错误输入有明确提示且程序不中断：3 分。
- 输出能清楚展示 ID、完成状态和标题：2 分。

## 四、代码质量与兼容性（10 分）

- 仅使用 Go 标准库，兼容 Go 1.16，无泛型：3 分。
- 命名清晰、职责合理、无无关功能和明显重复：3 分。
- 错误处理明确，无调试残留或不必要的全局可变状态：2 分。
- `go.mod`、目录结构和格式保持规范：2 分。

## 五、分支提交与交付规范（5 分）

- 在个人开发分支提交并推送，分支信息准确：2 分。
- 提交内容完整，不包含教师答案、第三方依赖或无关大文件：2 分。
- 教师选择该分支后可直接手动运行流水线：1 分。
