# 成绩等级实验

请在 `starter/grade.go` 中实现 `Grade(score int) (string, error)`。

成绩必须是 0–100（含两端）的整数。返回规则如下：

- A：90–100
- B：80–89
- C：70–79
- D：60–69
- F：0–59

0–100 是本函数的不变量：小于 0 或大于 100 的输入必须返回空字符串与 `ErrScoreOutOfRange`；有效输入返回对应等级与 `nil` 错误。

从仓库根目录运行验收测试：

```bash
go test -tags=exercise ./module01_basics/blocks/01_go_basics/lab/starter
```

初始测试失败是正常现象。实现后重复运行，直到全部通过。

## 三级提示

1. 一级：先把输入分成“有效”和“无效”两类，优先处理无效输入。
2. 二级：有效区间内有四个分界点：90、80、70、60；边界值属于较高等级。
3. 三级：按分数从高到低依次判断，每次命中后立即返回；剩余的有效分数都是 F。
