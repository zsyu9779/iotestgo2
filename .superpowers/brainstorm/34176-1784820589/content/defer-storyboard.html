Defer：两幕课堂动画脚本

右侧舞台从“内存数组”切换为“函数帧 + 待执行调用”；代码高亮仍按实际执行顺序移动。

第一幕 · 注册顺序与执行顺序
func work() {
　defer print("A")
　defer print("B")
　print("work")
}
  1. 进入 work，待执行区为空。
  2. 注册 A：A 卡片进入待执行区。
  3. 注册 B：B 卡片压到 A 上方。
  4. 预测：函数结束时先输出 A 还是 B？
  5. 执行 work，随后出现“准备返回”关口。
  6. B、A 依次弹出执行，再离开函数。
  7. 定格：后注册的调用先执行。
第二幕 · 参数快照与闭包读取
value := 1
defer print(value)
defer func() { print(value) }()
value = 2
  1. 创建变量格 value = 1。
  2. 注册普通调用：先求值参数，卡片保存 arg = 1。
  3. 注册闭包：卡片显示“执行时读取 value”。
  4. 赋值动画将变量格改为 value = 2。
  5. 预测：两个调用分别会打印什么？
  6. 闭包先执行并读取 2；普通调用再输出保存的 1。
  7. 定格：注册时求参数，执行时运行函数体。

页面如何表达“底层原理”

语言语义层（主动画）

  • defer 语句执行时，函数值和调用参数立即求值。
  • 外围函数返回前，已注册调用按逆序执行。
  • 闭包体真正执行时才读取它所访问的变量。

实现层（结尾注解）

  • “卡片栈”是解释语义的概念模型。
  • 编译器可能使用开放编码、栈上记录或其他优化。
  • 优化不能改变页面演示的可观察结果。
