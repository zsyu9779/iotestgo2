Slice：两幕课堂动画脚本

每次“下一步”只改变一个事实；预测页会锁住继续按钮，讲师揭晓后才播放状态变化。

第一幕 · 两个 Slice，共享一个数组
base := []int{1, 2, 3, 4}
view := base[1:3]
view[0] = 9
  1. 创建 base：Header 指向底层数组。
  2. 创建 view：新 Header 指向下标 1，显示各自 len/cap。
  3. 预测：修改 view[0] 后，base 会变吗？
  4. 数值 2 翻转为 9，两条指针保持不动。
  5. 同时高亮 base[1] 与 view[0]。
  6. 定格结论：Header 是值，数组元素仍可共享。
第二幕 · append 是否需要“搬家”
spare := make([]int, 2, 4)
reused := append(spare, 3)

full := make([]int, 2, 2)
grown := append(full, 3)
  1. 并排建立“容量有余”和“容量已满”两条轨道。
  2. 有余轨道：新元素落入原数组空槽，Header 的 len 增加。
  3. 预测：已满轨道还能写进原数组吗？
  4. 出现更大的新数组，已有元素逐个搬迁，新元素落位。
  5. grown 指向新数组；full 仍指向旧数组。
  6. 分别修改新旧数组，验证共享关系已经改变。
  7. 定格结论：是否共享取决于 append 是否重新分配。

动画中的技术边界

  • Header 展示为教学模型：指针、len、cap；不声称用户代码可以依赖其内存布局。
  • 新数组只标注“容量 ≥ 新长度”，不显示固定翻倍规则。
  • 移动效果用于表达元素被复制到新存储区域，不暗示地址或垃圾回收发生的具体时刻。
